---
title: Which systems does DesignCraft run on?
description: DesignCraft runs on Windows 11 and in a web browser.
order: 20
verified: 0.7.1
---

DesignCraft runs on Windows and in a modern web browser. macOS, Linux and FreeBSD are not supported.

- **Windows 11**: x64, arm64 and 32-bit x86 installers, plus portable zips.
- **Web**: a static site you host yourself (`designcraft-web-<version>.zip`). It runs on WebGPU and falls back to WebGL2. The web build has no control channel, and Save and Export download the file.

All files are on the [latest release](https://github.com/685ks/designcraft/releases/latest). See [Install DesignCraft](../getting-started/install.md) for steps.
